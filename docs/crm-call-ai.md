# Расшифровка и анализ звонков CRM

## Что обрабатывается

Фоновый обработчик берёт все завершённые звонки, которые:

- привязаны к карточке кандидата;
- имеют локально сохранённую запись;
- ещё не были успешно обработаны.

Источник звонка не имеет значения: Asterisk/Орбита, SIPOUT и Плюсофон проходят один и тот же конвейер. Будущая интеграция Билайна автоматически попадёт в него, если сохранит запись в `CrmCalls.RecordingStoragePath`.

Под текущим звонком расшифровка не показывается. Блок появляется только у завершённой записи в ленте карточки.

## Безопасное включение на сервере

Скомпрометированный или отправленный в чат токен сначала нужно отозвать и выпустить заново. Токен хранится только в серверном `.env`; в БД и браузер он не передаётся.

В `/opt/orbita/.env` добавить:

```dotenv
CERIO_AI_ENABLED=true
CERIO_AI_TOKEN=<НОВЫЙ_ТОКЕН>
CERIO_AI_PROCESS_FROM_UTC=2026-08-30T00:00:00Z
CERIO_AI_PROMPT_VERSION=recruiting-v1
```

`CERIO_AI_PROCESS_FROM_UTC` ограничивает первую очередь звонками не старше указанной UTC-даты. Для контролируемого запуска рекомендуется поставить дату включения. Если переменную оставить пустой, обработчик постепенно заберёт весь исторический архив сохранённых записей, начиная с самых новых.

Затем после доставки версии перезапустить API и Web обычной производственной командой проекта. Функция по умолчанию выключена, поэтому миграцию и интерфейс можно доставить до выдачи нового токена.

HTTP-клиент Cerio не пишет запросы в стандартный лог: токен передаётся API провайдера как query-параметр и не должен оказаться в логах.

## Корректировка промпта

Встроенный `recruiting-v1` оценивает:

- установление контакта с кандидатом;
- выявление ситуации и мотивации;
- ясность предложения;
- работу с вопросами и возражениями;
- фиксацию следующего шага;
- корректность и деловой тон.

Он требует строгий JSON, запрещает додумывать факты и снижает уверенность атрибуции, если по транскрипту нельзя надёжно отделить менеджера от кандидата.

Промпт можно заменить переменной `CERIO_AI_ANALYSIS_PROMPT`, а его версию — `CERIO_AI_PROMPT_VERSION`. При изменении критериев версию следует увеличить, например до `recruiting-v2`, чтобы отчёты разных методик можно было различать.

## Состояния обработки

- `pending` — запись поставлена в очередь;
- `transcribing` — аудио отправлено на расшифровку;
- `analyzing` — текст отправлен на анализ;
- `completed` — доступны расшифровка и структурированный анализ;
- `partial` — расшифровка сохранена, но структурированный анализ не получен;
- `failed` — расшифровка не получена.
- `skipped` — нулевая запись не отправлялась на распознавание.

Временные сетевые ошибки и ответы 429/5xx повторяются с увеличивающейся задержкой. Готовая расшифровка повторно не оплачивается, если упал только анализ. Один `CrmCall` имеет ровно одну строку результата, поэтому повторные вебхуки не создают дубли.

Звонки с длительностью `0` секунд не ставятся в очередь, не отправляются в Cerio и не входят в покрытие отчёта качества звонков.

## Проверка после запуска

Проверить применение миграции:

```sql
SELECT "MigrationId"
FROM "__EFMigrationsHistory"
WHERE "MigrationId" LIKE '%AddCrmCallAiInsights%';
```

Проверить очередь и результаты:

```sql
SELECT
    i."Status",
    count(*) AS "Количество",
    max(i."UpdatedAtUtc") AS "Последнее обновление"
FROM "CrmCallAiInsights" i
GROUP BY i."Status"
ORDER BY i."Status";
```

Проверить последние звонки с записью:

```sql
SELECT
    c."StartedAtUtc",
    c."Provider",
    c."ManagerUserId",
    c."RecordingStoragePath" IS NOT NULL AS "Запись сохранена",
    i."Status",
    i."Score",
    i."LastErrorCode"
FROM "CrmCalls" c
LEFT JOIN "CrmCallAiInsights" i ON i."CallId" = c."Id"
WHERE c."CardId" IS NOT NULL
  AND c."RecordingStoragePath" IS NOT NULL
ORDER BY c."StartedAtUtc" DESC
LIMIT 30;
```

После успешной обработки в карточке под аудиоплеером появляется кнопка «Расшифровка и анализ звонка». В аналитике CRM появляется самостоятельный блок «Качество звонков» с покрытием, средней оценкой, частыми сильными сторонами и зонами роста. Он не участвует в расчёте лидов, дозвонов и этапов воронки.
