# Документация LeadFlow

LeadFlow — это настольное приложение для Windows, которое превращает поток откликов из `Avito` в управляемый процесс: собрать, проверить, отфильтровать дубли, передать в `Bitrix24`, зафиксировать результат и показать аналитику команде.

## Что делает LeadFlow

- автоматически отслеживает новые отклики в аккаунтах `Avito`;
- работает с несколькими аккаунтами и отдельными браузерными профилями;
- проверяет дубли в локальной базе и, при необходимости, в `Bitrix24`;
- отправляет кандидатов в CRM без лишней ручной рутины;
- показывает статистику по откликам, CRM, ошибкам, дублям и объявлениям;
- сохраняет журнал событий для диагностики и контроля.

## Для кого это решение

LeadFlow особенно полезен для:

- рекрутинговых команд, которые работают с откликами из `Avito`;
- агентств и внутренних HR-отделов с несколькими аккаунтами;
- команд, которым важно быстро доводить кандидатов до `Bitrix24`;
- пользователей, которым нужен контроль над авторизацией, прокси, профилями и журналом действий.

## С чего начать

1. Откройте полное руководство пользователя.
2. Добавьте аккаунт `Avito` через локальный профиль или `AdsPower`.
3. Авторизуйтесь в нужном кабинете `Avito`.
4. Подключите `Bitrix24`, если нужна отправка в CRM.
5. Запустите мониторинг и контролируйте поток откликов в одном окне.
